This page contains information about all 364 Wikipedias which have officially been created under the auspices of the Wikimedia Foundation. The table below, however, excludes 16 Wikipedias that were closed, leaving a current total of 348 active Wikipedias. Wikipedias in other languages are being developed at the Wikimedia Incubator; languages which meet certain criteria can get their own wikis.

Notes

  • To start a Wikipedia in a new language, please see our language proposal policy and the Incubator manual.
  • If a Wikipedia becomes active and is not listed here, please post a notice on this article's talk page, including a link to all the relevant Wikipedia pages, and help promote the effort by announcing it on the Wikipedia-L mailing list, and at Wikimedia News.

The columns of the table:

  • Language – the language name in English (linked to the English Wikipedia article for the language)
  • Language (local) – the language name in the language itself
  • Wiki – the language code used in the wiki's URL address and in interwiki links to it (linked to the local Main Page)
  • All pages (sometimes Total) – the number of pages in all namespaces, including both articles (the official article count of each wiki) and non-articles (user pages, images, talk pages, project pages, categories, and templates).
  • Articles, Edits, Admins, Users – the official article count, numbers of edits, administrators and users (each linked to an appropriate local special page)
  • Active Users – registered users who have made at least one edit in the last thirty days.
  • Files – the number of locally uploaded files. Note that some large Wikipedias do not use local images or other media files and rely on Commons completely, so the value "0" is not a glitch (see also List of Wikipedias having zero local media files).
  • Depth – defined as Depth=EditsArticles⋅Non-ArticlesArticles⋅(1−ArticlesAll pages) with Non-Articles=All pages−Articles. It is a rough indicator of a Wikipedia’s collaborative quality, showing how frequently its articles are updated. It does not refer to academic quality.

Nonstandard language codes

Main article: Special language codes

These Wikipedias use language codes that do not conform to the ISO 639 standard, which is how wiki subdomains are chosen nowadays (mostly two-letter ISO 639-1 and three-letter ISO 639-2 language codes).

  1. als: – originally used for the Alsatian Wikipedia, which now encompasses the Alemannic dialects in general — the official code gsw is being considered as a replacement subdomain (note that als officially represents the unrelated language Tosk Albanian)
  2. bat-smg: – invented code used for the Samogitian Wikipedia (not the official code sgs)
  3. be-tarask: – invented code used for the Belarusian (Taraškievica) Wikipedia, combination of be for Belarusian and IETF language tag tarask for Taraškievica
  4. bh: – deprecated code used for the Bhojpuri Wikipedia (bh is the deprecated ISO 639-1 code for the Bihari languages, which Bhojpuri is a part of. The official code for Bhojpuri is bho)
  5. cbk-zam: – invented code used for the Zamboanga Chavacano Wikipedia (note that cbk is the correct code for the larger family of langugages Zamboanga Chavacano is a member of)
  6. fiu-vro: – invented code used for the Võro Wikipedia (not the official code vro — note that fiu is the official code for the family of languages Võro is a member of)
  7. ksh: – code used for the Ripuarian Wikipedia, even though ksh actually represents Kölsch (or Colognian), a subset of Ripuarian
  8. map-bms: – invented code used for the Banyumasan Wikipedia (note that map does represent the family of languages the Banyumasan dialect falls within)
  9. nds-nl: – invented code used for Dutch Low Saxon Wikipedia would technically be the correct code for Low Saxon spoken in the Netherlands (i.e., nds-NL), but is therefore redundant with nds:, the code used for the Low German/Low Saxon Wikipedia (note that nds is the correct code for the Low German/Low Saxon family of languages, which Dutch Low Saxon is a member of)
  10. nrm: – code used for the Norman Wikipedia (not the official code nrf — note that nrm is the official code for the completely unrelated language Narom)
  11. roa-rup: – invented code used for the Aromanian Wikipedia (not the official code rup — note that roa is the standard code for the larger family of Romance languages that Aromanian is a member of)
  12. roa-tara: – invented code used for the Tarantino Wikipedia (again, roa is the standard code for the large family of Romance languages that the Tarantino dialect falls within)
  13. sh: – deprecated code used for the Serbo-Croatian Wikipedia (valid IETF language tag, but not the official code hbs)
  14. simple: – invented code used for the Simple English Wikipedia (which is just an IETF language tag, not the formal code en-simple)
  15. zh-classical: – invented code used for the Classical Chinese Wikipedia (not the official code lzh)
  16. zh-min-nan: – invented code used for the Southern Min Wikipedia (not the official code nan)
  17. zh-yue: – invented code used for the Cantonese Wikipedia (not the official code yue)

Note that renaming wiki subdomains is very difficult, which is why so many of these nonstandard codes are still in use despite the existence of alternatives.

Redirects

  1. be-x-old: – redirects to be-tarask:(see above section)
  2. cz: – redirects to cs:(the Czech Wikipedia)
  3. dk: – redirects to da:(the Danish Wikipedia)
  4. gsw: – redirects to als:, but gsw.wikipedia.org points to incubator:Wp/gsw[4]
  5. jp: – redirects to ja:(the Japanese Wikipedia)
  6. mo: – redirects to ro:(as discussed above, the Moldovan Wikipedia now redirects to the Romanian Wikipedia)
  7. nan: – redirects to zh-min-nan:(the Southern Min Wikipedia)
  8. nb: – redirects to no:(the Norwegian Wikipedia using Bokmål orthography)
  9. nrf: – is not recognized by mediawiki as of 2026-03-19, but nrf.wikipedia.org redirects to nrm:(the Norman Wikipedia)[5]
  10. yue: – redirects to zh-yue:(the Cantonese Wikipedia)

Non-language subdomains

  1. nostalgia: – (alias: nost:) – A read-only snapshot of English Wikipedia's early days.
  2. sep11: – The Sep11wiki existed with a .wikipedia.org URL from 2001 to 2008, despite its totally different scope and purpose from all other Wikipedias. It was made read-only in 2006 and closed two years later.
  3. ten: – Used for Wikipedia 10, the 10th anniversary of Wikipedia celebration events. (Since "ten" is an ISO language code for the extinct Tama language in Colombia, the interwiki prefix "tenwiki:" is now used to refer to this site.)
  4. test: – test.wikipedia.org
  5. test2: – test2.wikipedia.org
